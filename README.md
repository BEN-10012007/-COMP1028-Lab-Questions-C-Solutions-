# -COMP1028-Lab-Questions-C-Solutions-
Welcome to COMP1028 collaborative learning repository!  This repository is created for students to share lab questions, C programming solutions, and ideas.  Our goal is to learn together by exploring different approaches to the same programming problems.  Everyone is encouraged to attempt each question independently before sharing their solutions. 

### What We Do
- Share COMP1028 lab questions and exercises.
- Upload our own C solutions and implementations.
- Compare different approaches to the same problem.
- Share our thought processes, logic, and problem-solving strategies.
- Discuss mistakes, debugging experiences, and alternative solutions.
- Learn from each other's ideas and improve together.

### Our Philosophy
**Think independently. Code individually. Learn collectively.**

AI can help us write code, but our ability to understand, reason, and solve problems is what truly matters.

Let's share not only our answers, but also the human thinking behind them.

*Different minds, different approaches, one learning community.*
